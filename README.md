# Émagramme AROME

Émagramme interactif (type 761) pour le vol libre : sondages AROME/ARPEGE de Météo-France via Open-Meteo, CAPE/CIN, base des cumulus, plafond thermique sol et relief, lecture commentée, didacticiel, sites de vol FFVL notés (décollage et thermique) avec balises de vent.

Page unique (`index.html`), sans serveur : les données sont téléchargées directement par le navigateur.

## Sources de données
- Prévisions : [Open-Meteo](https://open-meteo.com/en/docs/meteofrance-api) (Météo-France AROME / ARPEGE), CC BY 4.0
- Terrains et balises FFVL : [data.gouv.fr](https://www.data.gouv.fr/organizations/federation-francaise-de-vol-libre/datasets)
- Balises Pioupiou / OpenWindMap, OpenStreetMap (Overpass), ParaglidingEarth, fonds OpenTopoMap / OSM / Esri

Les notes sont indicatives : vérifiez toujours les bulletins officiels, les balises, la fiche du site et les consignes locales avant de voler.
